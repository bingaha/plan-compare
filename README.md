# plan-compare — Agent 套餐价格对比

一个纯静态的各平台 Agent/Coding 套餐性价比对比表，无需后端、无需安装。

**在线使用：https://bingaha.github.io/plan-compare/**

## 数据模型

数据按三层维护（页面右上角「管理数据」弹窗）：

1. **平台**：如 智谱 Z.ai
2. **模型价格**（平台下）：模型名 + 输入/输出/缓存命中单价（每 Mtok，与套餐额度同币种）
3. **套餐**（平台下）：名称 + 购买价(人民币) + 周期(月/季/年) + 方式 + 额度/用量 + 消耗倍率 + 价格倍率

主表是只读视图：每行自动 = 平台下 套餐 × 模型 的配对，价格与倍率在套餐/模型层只存一份、强制复用，改一处全部行同步。表格支持点表头排序、按列筛选（数值"≥"、文本"包含"）、每列最优值高亮；评分列按评分源自动分列。

- 额度制：`月均有效(亿tok) = 套餐内额度 ÷ (综合单价 × 价格倍率) ÷ 消耗倍率 ÷ 周期月数 ÷ 100`，`Mtoks/元 = 周期总有效Mtoks ÷ 购买价`
- 用量制：行内「改M」填该模型单周期可用量，`Mtoks/元 = (M ÷ 消耗倍率) ÷ (购买价 × 价格倍率)`
- 综合单价 = `输入占比 × (命中率 × 缓存价 + (1−命中率) × 输入价) + 输出占比 × 输出价`（顶部全局可调）

## 存储

- 首次打开把 `data.js` 内置数据整份复制进浏览器 localStorage，之后所有维护都发生在本地副本，改动自动保存。
- 「只看自己录入的」：隐藏"套餐与模型均为内置"的行。
- 「恢复内置默认」：丢弃本地副本重新播种。
- 「导出」：下载当前全部数据为 JSON 文件；「导入」：弹窗粘贴 JSON 文本，字段严格校验（多余/缺失/错型/非法取值直接拒绝，不做任何格式兼容）后**与现有数据合并**——global 取导入值，平台按 id、评分按「评分源+模型名」，同者更新、新者追加，不覆盖删除现有内容。完整格式说明悬停在页面最底部灰字区可见。
- 若内置数据更新：你本地没改过会自动跟上新版；改过则保留你的数据并提示。

## 内置数据说明

内置数据（data.js，v7）覆盖四个平台，数值为 2026-09 采集口径：

- **智谱 Z.ai**：模型为积分抵扣系数口径（积分/Mtok，GLM-5.3 输入 690 / 输出 2400 / 缓存 170；flash 230 / 800 / 56）。三档套餐各两套——高峰期（消耗倍率 2）与标准（消耗倍率 1），季付价 Lite ¥283.2 / Pro ¥1291.2 / Max ¥2587.2，额度分别为 128,571 / 771,428 / 1,800,000。高峰为周一至周五 14:00-18:00，非高峰（含周末全天）消耗减半的口径写在备注里。
- **CommandCode**：Goat DS-FLASH，月付 ¥72.5，额度 40（元口径），模型 Deepseek-Flash 0.15 / 0.6 / 0.003 元/Mtok。
- **R4coder**：deepseek-flash 5 美元套餐，月付 ¥36，额度 $30（美元标价口径），消耗倍率 2，模型 0.3 / 1.2 / 0.006 $/Mtok。
- **阶跃星辰StepFun**：Credit 月池全模型共享、无逐模型 API 价，按用量制建模——单模型「Step 全系列」承载共享池，usageM 为该套餐单周期总 Credit（Mtok）。月付 ¥49/99/199/699 对应 400/1600/8000/40000M，另有季付/年付与加油包（30 天按 1 月折算）。
- 评分：Artificial Analysis 智能指数（GLM-5.3 45 / flash 42）、LMArena Elo（1483/1475），仅作展示与筛选。

## 本地使用

任意静态服务器指向本目录即可（如 `python3 -m http.server 8877`），也可直接双击 `index.html`（data.js 经经典 script 加载，file:// 下同样可用）。
注意：localStorage 按浏览器 + 域名隔离，换浏览器/设备请用导出/导入迁移。
