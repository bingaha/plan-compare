# plan-compare — Agent 套餐价格对比

一个纯静态的各平台 Agent/Coding 套餐性价比对比表，无需后端、无需安装。

**在线使用：https://bingaha.github.io/plan-compare/**

## 使用

- 打开即用。表格默认按 `Mtoks/元`（每实付 1 元能获得的百万 token 数）降序排列，每列最优值绿色高亮。
- 所有单元格可直接编辑：改内置数据、增删套餐行、添加自己的评分源，改动**自动保存在浏览器 localStorage**，刷新/重开不丢。
- 「只看自己录入的」：隐藏全部内置套餐行，只显示你自己添加的行。
- 「恢复内置默认」：清空本地修改，回到出厂内置数据。
- 「导出 / 导入」：把当前全部数据导出为 JSON 文件（换浏览器或换设备时迁移用）。
- 顶部可调全局用量混合比（输入/缓存命中/输出占比），用于把"输入价/输出价/缓存价"折算成综合单价。

## 计算口径

- 额度制：`有效Mtoks = 套餐内额度 ÷ (综合单价 × 价格倍率) ÷ 消耗倍率`，`Mtoks/元 = 有效Mtoks ÷ 实付金额`
- 用量制：`Mtoks/元 = (用量M ÷ 消耗倍率) ÷ (购买价 × 价格倍率)`
- 综合单价 = `输入占比 × (命中率 × 缓存价 + (1−命中率) × 输入价) + 输出占比 × 输出价`
- 消耗倍率：名义用 1M 按 X 计费（如高峰期 1M 按 2M 计费填 2）；价格倍率：名义价格 × 倍率 = 实际价格（如 2 折渠道填 0.2）
- 购买价固定人民币；套餐内额度与模型单价按平台计价币种填写，两者同币种相除，无需汇率。

## 内置数据说明

内置为智谱 GLM Coding Plan 三档（Lite/Pro/Max）× GLM-5.3 / GLM-5.3-flash（2026-09 查证）：

- 月付价 Lite ¥118 / Pro ¥538 / Max ¥1,078 为第三方核对价（官方订阅页动态渲染，以订阅页实价为准）；
- API 单价为官方文档人民币价：GLM-5.3 ¥8/¥28/¥2，GLM-5.3-flash ¥0.8/¥2.8/¥0.23（输入/输出/缓存命中，每 Mtok）；
- 套餐内额度按官方"订阅费 15–30 倍 API 价值"口径取 15 倍保守值；官方另有周 Token 参考表口径（见各行备注）。
- 评分：Artificial Analysis 智能指数（45/42）、LMArena Elo（1483/1475），仅作展示与筛选。

## 本地使用

直接双击 `index.html` 即可（数据内置在 `data.js`，经经典 script 加载，file:// 下同样可用）。
注意：localStorage 按浏览器 + 域名隔离，GitHub Pages 上保存的数据只存在于你当前使用的浏览器；换环境请用导出/导入迁移。
